# 弹幕插件 · 设计方案

> 插件名：`@local/danmaku`（弹幕氛围）
> 状态：**已开发并安装**。本文档记录设计与实现，及实现与最初设计的偏差。
> 验证状态：逻辑与文案校验全部通过；**未做浏览器实机视觉验证**（当前会话无浏览器控制权）。

---

## 1. 一句话目标

在 DSH 页面上飘过弹幕，用户可在 **工作狂 / 禅 / 鼓励师 / 陪伴** 四种氛围间切换；每种氛围的**频率、文案、配色、动效**都不同，其中禅模式采用**竖向水滴**而非横向飘过。

---

## 2. 已确认的决策

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 模式集合 | 就这 4 种：工作狂、禅、鼓励师、陪伴 |
| 2 | 是否感知真实事件 | **v1 不感知**。纯随机文案池，不接会话/工具事件 |
| 3 | 禅模式动效 | **竖向水滴**（下落 + 淡出），其余三种横向飘过 |
| 4 | 交互形态 | **A 双入口**：右下角常驻胶囊 + 设置页 General 行 |
| 5 | 配色 | **方案 3 混合**：容器/控件用主题 token，每条弹幕带自有色相（装饰例外） |
| 6 | 默认状态 | **默认开启「鼓励师」** |

---

## 3. 四种模式定义

频率 = 平均发射间隔，实际在区间内随机抖动，避免机械节拍感。

| | 工作狂 | 禅 | 鼓励师（默认） | 陪伴 |
|---|---|---|---|---|
| 频率 | 快 · 约 5s 一条 | 极低 · 约 30s 一条 | 适中 · 约 11s 一条 | 低而持续 · 约 17s 一条 |
| 方向 | 横向、快速 | **竖向堆叠** | 横向、中速 | 横向、慢速 |
| 色相 | 冷红 `352°` / 橙红 `8°` `22°` / 品红 `340°` | 青灰 `186°` `196°` `176°` | **暖黄 `36°` `46°` / 橙 `22°` / 黄绿 `100°`** | 紫 `268°` `288°` / 蓝 `248°` `216°` |
| 基准字号 | **15px**，粗体 700 | **13px**，细体 400，字距 0.2em | **15px**，500 | **15px**，500 |
| 文字处理 | 着色字 + 近黑描边 | 同左，逐字居中 | 同左 | 同左 |
| 语气 | 催促、教练式、低气压 | 极简、呼吸感 | 温暖、具体、给正向反馈 | 像朋友在旁边聊日常 |

> 所有模式的字号都可在面板里按 0.7x ~ 1.8x 调整。

**文案池规模**：工作狂 15 条起、禅 9 条起、鼓励师 20 条起、陪伴 17 条起；中英文各一套。

## 4. 交互设计

```
┌────────────────────────────────────────────┐
│                                            │
│   ╭─────────╮            ╭──────────────╮  │
│   │ 鼓励师~ │  ← 弹幕    │ 你刚才那段…  │  │
│   ╰─────────╯            ╰──────────────╯  │
│                                            │
│                             ┌────────────┐ │
│                             │ 弹幕氛围   │ │ ← 点击胶囊展开
│                             │ ● 工作狂   │ │
│                             │ ● 禅       │ │
│                             │ ✓ 鼓励师   │ │
│                             │ ● 陪伴     │ │
│                             │ 节奏 ──●── │ │
│                             │ 更多设置 → │ │
│                             └────────────┘ │
│                        ● 弹幕 鼓励师        │ ← 常驻胶囊（半透明）
└────────────────────────────────────────────┘
```

- **胶囊**：右下角，半透明（悬停/聚焦变实），显示当前模式色点 + 名称，点击展开面板
- **面板**：四个模式按钮（单选）+「关闭」+ 节奏 / 不透明度 / 字号三个滑杆
- **关闭方式**：Esc、点击外部、点面板里的「关闭」项
- **设置页**：General 分区增加一行「弹幕」，带开关（开关控制模式的有无）
- **不挡操作**：整层 `pointer-events: none`，只有胶囊和面板可点击；弹幕条目永不拦截鼠标

## 5. 技术架构

```
danmaku/
├── package.json          # bundle 声明 + client 入口
├── cordis.patch.yml      # 插入插件行
├── index.js              # Host 端空实现（纯前端插件）
├── client.js             # 全部逻辑
├── locale/{zh,en}.json   # meta 元信息 + 全部 UI 文案 + 文案池
├── docs/DETAIL.md        # 插件市场详情页
├── docs/DESIGN.md        # 本文档
└── icon.svg              # 原创图标
```

**挂载点**（已查证安装版源码）：

| 用途 | 槽位 | 说明 |
|---|---|---|
| 弹幕层 + 胶囊 | `shell.overlay` | list 型、root 作用域，覆盖全窗口、点击穿透 |
| 设置行 | `settings.general.item` | General 分区的可插入行 |

**引擎要点**
- 横向弹幕 = **每条一个 CSS 位移动画**，主线程只跑一个调度定时器 → 高密度也不掉帧
- 禅模式 = **逐字竖向堆叠** + 下落淡出动画（见 6.3）
- **泳道分配**：记录每条泳道上一条弹幕何时离开起点，避免重叠
- **同屏上限**：横向 ≤ 泳道数+3，禅 ≤ 4，防止 DOM 堆积
- **密度**：滑杆同时影响发射间隔与速度；间隔在 0.7~1.35 倍内随机抖动
- **字号**：用户可调 0.7x ~ 1.8x，叠加在各模式基准字号上，钳制在 10~40px
- **状态**：`localStorage` 保存（模式、密度、不透明度、字号），刷新保持
- **隐藏标签页时暂停**发射（`visibilitychange`），恢复时不补发积压

**必须避开的坑**：`shell.overlay` 的容器对子元素强制 `pointer-events: auto`，所以根节点必须显式写成 `none`，否则整页被一层透明 div 吃掉交互。

## 6. 配色与可读性

### 6.1 结论：去掉底色胶囊，改用描边

最初给每条弹幕加了同色相的半透明胶囊做底色。实际问题是**文字和底色太接近**，工作狂模式下对比度只有 1.06:1，几乎看不见。

取消胶囊后又发现更深一层的问题。弹幕要飘过整个窗口，而窗口里有白底对话区、浅灰侧栏、深色代码块、深色主题。实测单色文字在某些背景上会彻底消失：

| 方案 | 最差对比度 |
|---|---|
| 浅主题深红字 | 1.69:1（飘过深色内容时） |
| 深主题亮字 | 1.35:1（飘过白色内容时） |
| 暖色字（鼓励师） | 1.03:1 |

**任何固定颜色的小字，都会在某一类背景上消失。** 这不是调色能解决的。

### 6.2 最终方案：着色文字 + 近黑描边

```
文字：hsl(色相, 饱和度, 明度)  —— 保留模式情绪
描边：rgba(8,8,12,.92)，2.5px
光晕：0 0 3px + 0 0 8px 黑色
```

原理：描边给文字一个**恒定的局部背景**，可读性不再取决于背后是什么内容。

关键实现细节：`paint-order: stroke fill` 让描边画在字形**背后**，否则描边会吃掉笔画、字变细。

两种主题都用**浅色着色文字**，因为描边才是常量。实测全部 15 个色相组合对描边的最低对比度是 **5.08:1**。

### 6.3 禅模式：竖向文字

**不使用 `writing-mode: vertical-rl`。** 该属性依赖日文竖排专用的替代字形（`、` `。` 会旋转到右上/左下），中文字符没有这套竖排变体，句号会明显偏离居中位置。

改为**逐字纵向堆叠**：每个字符一个盒子，`flex-direction: column` 从上往下排，每个盒子内居中。这样标点和文字都能正确居中，符合中文竖排的阅读方式。

**中文池不含标点**。去掉 `，。` 后，竖排就是一个干净的词列，视觉上更接近"禅"的留白感。

**英文保留完整句子，横排显示**。英文去标点会破坏句义（`Listen. The keyboard stopped.` 去掉句号变成 `Listen The keyboard stopped`），所以带标点的文案自动改为横向单行。判断规则：含标点或空格 → 横排；纯中文词 → 竖排。

实现细节：

| 事项 | 处理 |
|---|---|
| 结构 | 外层 `dmb-drop` 承载下落动画，内层 `dmb-col` 逐字堆叠（或 `dmb-run` 横排） |
| 字号 | 通过 `--dmb-size` 变量传递 |
| 描边粗细 | `calc(var(--dmb-size) * .12)`，随字号缩放 |
| 列宽 | 固定 `1.3em`，保证每个字格里居中 |
| 水平位置 | **随机取 x**，避开同屏已有的列（见 6.3.1） |
| 测试 | `verify-column-dom.cjs` 验结构，`verify-zen-layout.cjs` 验横竖判断，`verify-zen-placement.cjs` 验分布 |

#### 6.3.1 修复：禅模式只在左侧出现

最初用「泳道 → x 坐标」映射，`pickLane()` 总是返回**第一个空闲泳道**。禅模式 30 秒才发一条，上一条 13 秒内就消失了，所以每次都是泳道 0，也就是**永远在同一个位置**（1440px 窗口下固定 115px）。

修复方式是放弃泳道到 x 的映射，**直接随机取 x**，并避开同屏仍在显示的列。实测 400 次投放横跨 59px~1330px，左中右三段分布 132/152/116，同屏 4 列时最近间距 252px。

### 6.4 控件配色

胶囊、面板、滑杆、开关、边框、正文全部使用 `--dsw-alias-*` 主题 token，自动适配深浅色。只有弹幕文字用模式自有色相，这是平台允许的装饰例外。

## 7. 边界情况与约束

| 情况 | 处理 |
|---|---|
| 用户开了"减少动态效果" | 原地淡入淡出（4.2s），每条占据独立纵向槽位，不会重叠 |
| 窗口很窄 / 很矮 | 水滴横向位置做上下限钳制；泳道数固定为模式常量（**未按窗口高度收缩**，见第 11 节） |
| 长时间挂着 | 单条弹幕 DOM 在出场后立即移除，节点数恒定 |
| 切模式 | 立即清空旧弹幕并重新调度，切换感明显 |
| 多标签页/多窗口 | 各自独立（localStorage 只存偏好，不监听 `storage` 事件） |
| 中英文切换 | 文案走 locale 字典，下一条弹幕立即使用新语言 |

## 10. 内容生成策略

### 10.1 结论：句子写死，呈现动态

| 层 | 是否动态 | 说明 |
|---|---|---|
| **说什么（句子）** | ❌ 写死 | 四个模式各有一个预写文案池，放在 locale 字典里，中英双语 |
| **怎么飘（呈现）** | ✅ 动态 | 每次发射随机选句、随机泳道、随机色相、随机抖动间隔、速度浮动 |

"活的是怎么飘，不是说什么"。

### 10.2 v1 范围为「扩池子」

用户已确认：**先扩池子（方案 A）**，模板变量填充（方案 B）留到 v1.1。

- 每个模式扩到 **40+ 条**，中英各一套
- 配套 **"最近 N 条不重复"** 机制：每个模式记住最近发出的句子索引，从池中随机抽时避开，直到池子轮完一遍再重置
- 这样即使 40 条池子，短时间内也不会出现重复感

### 10.3 为什么不做真动态生成

| 方案 | 做法 | 代价 | 结论 |
|---|---|---|---|
| A. 扩池子 | 每模式 40+ 条 + 防重复 | 纯文本工作 | ✅ **v1 采用** |
| B. 模板 + 变量 | 「已经 {时长} 了，歇会儿？」运行时填真实值 | 中等，需前端取会话时长/时钟 | ⏭ v1.1 |
| C. 接模型生成 | Host 端按上下文生成一句 | 要 Host + 消耗 token + 延迟 + 不可控 | ❌ 不做 |

C 不做的理由：为飘一句话调一次模型不划算；且与"v1 不感知会话"的决策冲突。

### 10.4 已知短板（如实记录）

- 池子再大，长期挂着仍会重复
- 鼓励师说"你刚才那段写得挺清楚"时，它**看不见你写了什么**，属于善意的空话。这一点在插件详情页中会写明，避免用户误解为"智能感知"。

### 10.5 实际池子规模

| 模式 | 条数 |
|---|---|
| 工作狂 | 42 |
| 禅 | 14 |
| 鼓励师 | 41 |
| 陪伴 | 41 |

禅模式刻意保持精简，符合"少即是多"的语气。

## 11. 实现与早期设计的偏差（如实记录）

经 UI/UX 审查后修复的问题：

| 问题 | 原状 | 现状 |
|---|---|---|
| 文字与胶囊同明度 | 工作狂对比度 1.06:1，糊成一片 | **去掉胶囊**，改近黑描边，全部色相 ≥ 5.08:1 |
| 字号偏小 | 12~13px | 15px（禅 13px） |
| 面板无"关闭"项 | 只能去设置页关 | 面板加了第 5 项「关闭」 |
| 设置开关重置模式 | 关掉再开总是回到鼓励师 | 记住上次所选模式 |
| "更多设置"假链接 | 点了没反应 | 已删除 |
| 设置描述与事实不符 | "在这里选择氛围" | 改为"在这里开关，氛围在胶囊里选" |
| 减少动效下水滴重叠 | 泳道占用 2.2s < 实际显示 4.2s | 占用时间与显示时长一致，且各占独立槽位 |
| 开关滑块硬编码 `#fff` | 浅色主题白底白滑块 | 改用 `--dsw-alias-switch-thumb` token |
| 节奏滑杆无值提示 | 用户不知道当前值 | 显示「慢 / 标准 / 快」 |
| CJK 宽度估算偏小 | 中文长句尾部被提前裁掉 | 按中文 1em、拉丁 0.55em 分别估算 |
| 英文含品牌名 | "Xiaohongshu? No. Stay." | 改为中性表达 |
| Escape 抢占全局 | 捕获阶段 stopPropagation | 仅当事件源在面板内时处理 |

**仍然存在的限制**：

1. **泳道数固定**，不随窗口高度收缩（窗口极矮时弹幕会偏密）
2. **弹幕对读屏不可闻**（`aria-hidden`），读屏用户只能用胶囊和开关
3. **首次发现性弱**：胶囊默认 55% 不透明，没有新手引导
4. **没有浏览器实机验证**：以上所有结论来自代码审查与自动化脚本
